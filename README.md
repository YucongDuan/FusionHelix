# FusionHelix / 碳硅共演螺旋

**A breakthrough is not higher performance. It is a new joint capability that survives ablation while identity, agency, welfare, privacy, reversibility and future options remain protected.**

FusionHelix is an open-source carbon-silicon co-evolution and phase-transition runtime.

It is designed for:
- external AI cognition,
- adaptive wearables,
- prosthetics and sensorimotor loops,
- brain-computer interfaces,
- living-silicon / organoid computing,
- future identity- or lineage-altering interventions.

## Core spiral

```text
Carbon baseline
-> Silicon baseline
-> Interface map
-> Bidirectional adaptation
-> Composite capability
-> Embodied outcome
-> Identity/welfare/privacy/reversibility audit
-> Capability and value return
-> Phase transition
-> Independent replication
-> next helix turn
```

A closed circle returns to the same state. A helix changes carbon, silicon and the composite on every turn.

## Quick start

```bash
python fusionhelix.py new data/samples/program_input.json --out outputs/my_program.json
python fusionhelix.py event outputs/my_program.json data/samples/event_input.json --out outputs/my_program_v2.json
python fusionhelix.py audit data/samples/speech_neuroprosthesis_breakthrough.json
python fusionhelix.py phase-receipt data/samples/speech_neuroprosthesis_breakthrough.json --out outputs/phase.json
python fusionhelix.py decouple data/samples/organoid_welfare_blocked.json --out outputs/decouple.json
python fusionhelix.py compare data/samples/speech_neuroprosthesis_breakthrough.json data/samples/wearable_lockin_open.json --out outputs/comparison.json
```

## What makes a fusion claim valid?

An E3+ composite-capability event must show:
- carbon alone was tested,
- silicon alone was tested,
- the joint system succeeded under matched constraints,
- the capability is genuinely new for the composite,
- an ablation protocol exists,
- an independent observer reviewed it.

## Hard boundaries

- No universal fusion score.
- No human-worth ranking.
- No phenomenal-consciousness claim.
- No raw neural or biological data in public exports.
- No living-substrate escalation without origin, consent, stimulation limits, termination and independent ethics review.
- No irreversible FB5 deployment through this runtime.
- No automatic external action.
- No new repository is created automatically; integrate into an existing flagship first.
